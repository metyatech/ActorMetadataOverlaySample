# Demo specification

`demo-spec.json` is the public semantic source of truth for the Sample map and for the one-way Sample-to-Capture sync.

It describes actor identity, labels, Actor Tags, Gameplay Tags, folders, semantic Data Layers, public properties, sample transforms, expected overlay lines, rules, and capture roles. Private Capture Hosts may supply their own transform and camera layout keyed by `captureRole`; those private transforms do not belong in this repository.
